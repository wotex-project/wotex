# CoAP / DTLS / OSCORE physical lab

**Owner:** `wotex-coap`

Status: planned physical lane.

## Hardware class

Select a small programmable constrained node with an open CoAP stack or a finished CoAP device that does not require vendor SaaS.

## Acceptance

- GET/PUT/POST interaction mapping;
- Observe lifecycle;
- confirmable retransmission under packet loss;
- duplicate message handling;
- blockwise transfer where owned by the package;
- DTLS/OSCORE profile selected explicitly;
- credential/key material outside TDs;
- peer reboot and sequence/replay behaviour.

Do not purchase hardware until the accepted package spec identifies the physical operations that remain unproven.
