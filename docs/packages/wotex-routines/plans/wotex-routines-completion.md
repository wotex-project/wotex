# Optional routines completion contract

Version: 0.1.0. Updated: 2026-10-13. Target only; implementation/evidence missing.

The WRO.01–04 catalogue is a prospective package contract. The current family
still has eighteen source packages. This documentation tree is intentionally
not part of the generated family catalogue until the optional package is
scaffolded and registered in tooling. Do not invent implementation modules,
test paths or archive evidence to make it appear delivered.

| Stage | Required artifact | Completion |
| --- | --- | --- |
| R1 basis | WRO.01 closed types/schemas/errors and Continuum field reconciliation | Independent scalar/event/fast/slow/media values, unknown-required refusal and exact conversions |
| R2 scaffold/kernel | Explicit nineteenth optional package and dependency/tooling graph; WRO.02 codecs/IR/limits | No base/core/protocol dependency on routines; load has no I/O; public archive decisions match independent reference |
| R3 temporal | Direct public ExBooking SP.08 adapter and WRO.03 driver/host callbacks | Original occurrence and policy parity; no availability clipping used as trigger identity; real consumer transaction/fault evidence |
| R4 composition | Complete-set collection seam and run/step/root/unknown transition contracts | Bounded sequence/parallel/wait/subroutine profiles; no lost originals, hidden compensation or replay |
| R5 analysis | WRO.04 model scopes, result axes and evidence/correspondence | Independent concrete traces and behavioral mutations; unsupported/inconclusive cannot become admission |
| R6 independent consumers | At least two real extracted-package archive consumers | Same generic corpus, private state/policy in each consumer, no cross-calls or consumer terminology in package |

All stages remain planned. ExBooking owns its generic producer API in its own
repository; ExMaude owns generic checker changes. No dependency version is
selected by this document. Before each consuming stage select coherent public
producer releases and verify the actual archive closure.

Package tests separately establish pure semantics, archive interoperability
and owned driver lifecycle. Installed clocks, native containment and physical
actuator operation are additional consumer evidence, never inferred from a
successful simulation or catalogue check. No reference to a product/customer,
mandatory AI, external workflow service, storage engine or booking facade
belongs in this package.
