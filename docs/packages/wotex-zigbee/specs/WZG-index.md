# WZG specification index

The planned package is a generic Zigbee NCP host, network and ZCL layer. Consumer profiles retain device-family semantics.

- [WZG.01 — Coordinator host](WZG.01-library-contract.md), 0.2.0-target.
- [WZG.02 — Network continuity and ZCL](WZG.02-network-zcl.md), 0.2.0-target.
- [WZG.03 — Hardware evidence](WZG.03-hardware-evidence.md), 0.2.0-target.
- [Catalogue](catalogue.yaml).

Documentation does not imply a package binary or a working coordinator. Actual serial/NCP and standards revisions must be pinned before implementation qualification. Repository tooling registration is part of that implementation work.
