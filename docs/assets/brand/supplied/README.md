# Supplied Carbon fold variants

These three SVGs are byte-for-byte copies from the maintainer-supplied
`Wotex/Logo` asset set. They preserve the supplied gradients and transparent
bounds. The source filenames call the neutral gradient treatments “monochrome”.

The supplied `master.svg`, `logo-light.svg` and `logo-dark.svg` have identical
bytes and the Default hash above. One asset preserves those three aliases.

All three treatments declare 1077 × 765 pixels and the viewBox
`-30 -36 359 255`. On 22 October 2026, XML/reference checks confirmed identical
path, group and use geometry, five paths, six gradient definitions and local
clipping references. They contain no raster images, text, scripts, event
handlers, filters, animation or external resource references.

The [previously selected logo](../wotex-logo-light.svg) and
[native Figma exports](../exports/README.md) retain their existing identities.
These supplied treatments still need reconciliation with the native brand
components and their theme bindings. Their presence here does not establish a
completed Figma import. See the [asset notice](../NOTICE).
