# Selected WoTEx identity exports

These artwork files come from the selected native Figma identity page. The
maintainer selected the supplied default mark. Dark and monochrome treatments,
minimum sizes and application layouts are design proposals for review.

The [original SVG](../wotex-logo-light.svg) remains byte-for-byte unchanged;
its SHA-256 is
`db6988632bafbc369ccf12cbb939a0b097886b424d8135d7e6a5cd4fbc19bc9c`.
The SVG exports below are native Figma representations, not byte copies of that
source. Keep the [asset notice](../NOTICE) with them.

The additional [supplied Carbon fold variants](../supplied/README.md) preserve
the maintainer's neutral light/dark gradients. Their native Figma adoption
remains open; the exports below retain their original source frames.

The [native identity Spec](https://www.figma.com/design/R5PCVQOfoJV6rrsJ6ZTSv0/WoTEx-Brand?node-id=20-219)
owns usage, clear space, sizes, color, typography, voice and imagery. The
[brand design plan](../../../packages/wotex-lab/plans/brand-and-lab-design.md)
owns acceptance. Repository source baseline:
`ac35db6860c2b648296ca5d44558407b2d10dedf`, package `packages/wotex-lab`.

## Treatments and destinations

Use Default on white/pale surfaces and Dark on charcoal surfaces. Dark changes
only the two darkest gradient colors: `#181D27` to `#D6DBE3`, and `#303644` to
`#9097A5`. Monochrome uses one solid foreground. The mark has no added box,
caption, outline or shadow; preserve its aspect ratio and transparent bounds.

Standalone marks have a proposed minimum width of 24 pixels; compact product
chrome uses 28 pixels. Keep one quarter of the visible mark height clear around
its artwork. Favicon exports use their dedicated 32-pixel composition.

SVG masters, application PNGs and favicons are transparent. Choose the light or
dark PNG for its destination background. Social cards use an opaque white
canvas with the mark alone. The repository card follows
[GitHub's 1280 × 640 guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
The 1200 × 630 social card is a layout choice, not an Open Graph requirement.
No repository setting, application manifest or deployment was changed.

## Export checks

On 2026-10-21, the three SVGs passed XML/reference checks with no scripts,
external images, text or raster content. All three have the same six path data
values and `0 0 1077 765` viewBox; their paint treatments differ. The original
source hash above was checked separately.

All eight PNGs passed signature, chunk-integrity and dimension checks. Favicon
and application exports retain transparent pixels. Each light/dark pair has
identical alpha geometry. Their visible artwork fits a centered circle of
radius 40% of the canvas size. The measured maximum radii were 10.1242 of 12.8
pixels for the favicon, 62.6139 of 76.8 for the 192-pixel icon, and 167.0045 of
204.8 for the 512-pixel icon. The crop rule follows the
[Web Application Manifest Working Draft of 16 October 2026](https://www.w3.org/TR/2026/WD-appmanifest-20261016/#icon-masks).
It is an artwork check, not manifest/browser conformance. Native treatment,
size, application and social specimens were visually reviewed. No font binary
is distributed in these exports.
