# Standards provenance

Observed and retrieved: 2026-09-02

## W3C WoT Discovery

- Exact revision: W3C Recommendation, 2023-12-05
- Revision URL:
  <https://www.w3.org/TR/2023/REC-wot-discovery-20231205/>
- Current-series URL: <https://www.w3.org/TR/wot-discovery/>
- Classification: primary normative source
- Used for: Things API CRUDL behavior, registration information, anonymous
  identifiers, validation guidance, pagination, expiry, security ordering, and
  well-known Introduction
- Revalidation trigger: a superseding Recommendation or an erratum that changes
  an implemented assertion

- Exact revision: W3C Recommendation, 2023-12-05

  <https://www.w3.org/TR/2023/REC-wot-thing-description11-20231205/>

## IETF sources incorporated by reference

- RFC 7396, JSON Merge Patch: <https://www.rfc-editor.org/rfc/rfc7396>
- RFC 3339, Internet date and time: <https://www.rfc-editor.org/rfc/rfc3339>
- RFC 8288, Web Linking: <https://www.rfc-editor.org/rfc/rfc8288>
- RFC 7807, Problem Details as cited by the Discovery Recommendation:
  <https://www.rfc-editor.org/rfc/rfc7807>

These are primary standards sources. The package implements RFC 7396 map
mechanics. Web Linking and Problem Details are transport-host responsibilities.
