# Governance

The Wotex Project maintainers steward this repository. Maintainers accept
specifications, approve compatibility changes, review security fixes, and sign
releases. A release requires two maintainer reviews when more than one active
maintainer is available; otherwise the sole maintainer records the decision and
evidence publicly.

W3C claims require an exact source revision and reproducible tests. No
maintainer may grant certification on behalf of W3C. Security reports are
handled privately until coordinated disclosure.

Repository roles are earned through sustained, reviewed contributions. Role
changes and compatibility decisions are recorded in the repository. Project
assets and release credentials are held by maintainers under least-privilege
access.
