# Specification delivery

1. Identify the owning normative requirement and exact standard revision.
2. State ownership and explicit non-ownership.
3. Define values, errors, determinism, limits, and compatibility before code.
4. Add valid, invalid, boundary, and extension-preservation vectors.
5. Implement only the claimed cells.
6. Run package checks and record exact evidence.
7. Reject a completion claim when implementation, docs, and vectors disagree.
