# Web of Things terminology rule

The W3C Web of Things vocabulary is canonical. Capitalize Property, Action, and
Event when they name Interaction Affordance categories. A Thing Description is
the standardized description, not a device row or digital twin. A Form carries
protocol binding metadata; it does not authorize an operation or prove a
physical effect.

Thing Description 1.1 is the production baseline. Draft specifications and
group notes must be labelled as such and cannot silently widen conformance.
