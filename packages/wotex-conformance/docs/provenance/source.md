# Source provenance

The implementation, specifications, JSON schemas, tests, and initial synthetic
vectors in this baseline are authored for this public repository under Apache
License 2.0.

Dependencies are declared in `mix.exs` and fixed by `mix.lock`. Their licenses
and source metadata are provided by the package registry and must be reviewed
before a release.

No consumer source, consumer fixture, customer data, credential, internal path,
or non-public service contract is part of this repository.
