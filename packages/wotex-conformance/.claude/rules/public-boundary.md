# Public-source boundary

- Use only public project identity, standards references, synthetic fixtures,
  and host-neutral examples.
- Say `consumer` or `consumer host` for an integrating system.
- Do not include consumer product names, namespaces, repositories, private
  paths, customer data, internal service identifiers, or copied policy text.
- Do not reserve package names with empty code or placeholder claims.
- Imported material requires a provenance record and compatible notice.
- Source visibility is distinct from package readiness, API stability,
  interoperability, and certification.
