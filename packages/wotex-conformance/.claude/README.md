# Instruction layout

`CLAUDE.md` contains the always-on repository contract.

- `rules/wot.md` owns terminology and standards-claim discipline.
- `rules/elixir.md` owns library and runtime behavior.
- `rules/testing.md` owns evidence and test isolation.
- `rules/public-boundary.md` owns public-source hygiene.
- `skills/conformance-contract/SKILL.md` applies to claim, vector, runner, and
  report changes.
- `skills/quality-gates/SKILL.md` applies before handoff.
